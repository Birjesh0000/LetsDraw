## PART 1 — Create your Profile README (biggest visual upgrade)

A "Profile README" is a special repo named **exactly like your username** (`Birjesh0000`).  
Whatever you put in its `README.md` appears on your GitHub profile page.

**Steps:**

- [ ] **1.1** Go to [https://github.com/new](https://github.com/new)
- [ ] **1.2** In the **Repository name** field, type exactly: `Birjesh0000`
- [ ] **1.3** Make sure **Public** is selected
- [ ] **1.4** Tick ✅ **"Add a README file"**
- [ ] **1.5** Click **"Create repository"** — GitHub will show a green banner saying  
       *"Birjesh0000/Birjesh0000 is a special repository!"*
- [ ] **1.6** Click the **pencil (edit) icon** on the generated `README.md`
- [ ] **1.7** **Select all** and **delete** the default content
- [ ] **1.8** Open the file [`profile-readme/README.md`](./profile-readme/README.md) in this repo,  
       copy the entire contents, and **paste** it into the GitHub editor
- [ ] **1.9** Replace every `YOUR_*` placeholder with your real data:
  - `YOUR_LINKEDIN` → your LinkedIn profile URL slug (e.g. `in/birjesh-xyz`)
  - `YOUR_EMAIL@gmail.com` → your actual email address
  - `YOUR_PORTFOLIO_LINK` → your portfolio website (or remove the badge if none yet)
  - `YOUR_RECYCLEHUB_DEMO_LINK` / `YOUR_VIDYASETU_DEMO_LINK` → live demo URLs
  - `[X]+` in achievements → your actual LeetCode count
- [ ] **1.10** Click **"Commit changes…"** → **"Commit directly to the main branch"** → **Commit**
- [ ] **1.11** Visit [https://github.com/Birjesh0000](https://github.com/Birjesh0000) to confirm it looks good
